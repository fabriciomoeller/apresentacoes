# Bella Top — Manufatura, MRP, Custos & Qualidade no EME4

## Visão geral

Apresentação executiva Slidev do EME4 para a [Bella Top Embalagens](https://www.bellatop.com.br/) (sacolas e sacos personalizados em TNT e algodão, Blumenau/SC). O fio condutor é a manufatura **sob encomenda configurável**: cada pedido tem medida, cor, alça e arte próprias.

## Objetivos

- Mostrar a engenharia de produto com estrutura-mãe e componentes **Opcionais** na BOM.
- Mostrar o MRP híbrido: personalizado MTO, pronta-entrega MTS, insumos em estoque planejado.
- Mostrar custo real por pedido, qualidade por etapa e formulários web como personalização.
